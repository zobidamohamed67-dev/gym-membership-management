# 🏋️ GYM Membership Management System

A simple CLI (Command Line Interface) Python application designed to manage gym memberships efficiently using Object-Oriented Programming (OOP) concepts.

## 🚀 Features
* **Add New Members:** Register members with first name, last name, unique ID, and membership status (active/inactive).
* **Display Members:** View complete details of all registered members.
* **Search Functionality:** Multi-criteria search (by Membership ID, First Name, or Status).
* **Dynamic CLI UI:** Clean console screen transitions and formatted output.

## 🛠️ Tech Stack
* Python 3
* Built-in modules: `os`, `time`
